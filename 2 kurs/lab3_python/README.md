# Лабораторная работа 3 Порождающие шаблоны проектирования

Текстовая RPG на Python по приложенному учебному примеру. Игровая логика сохранена. Восстановлены переносы строк, потерянные в DOCX, код распределён по модулям и добавлены файлы пакетов. Дополнительно подготовлены проверки, результат демонстрации и подробный разбор.

## Запуск

Нужен Python 3.10 или новее. Сторонние зависимости не нужны. Откройте терминал в этой папке, рядом с каталогом `labs`.

```bash
python -m labs.lab3.demo
python -m labs.lab3.main
python -m unittest discover -s tests -v
```

Если в системе используется команда `python3`, замените `python` на `python3`. В Windows можно использовать `py -3`. Файлы `main.py` и `demo.py` запускаются как модули, поскольку используют относительные импорты.

## Состав

- `labs/lab3` — полный исходный код игры из примера.
- `tests/test_lab3.py` — 20 автоматических проверок поведения.
- `demo_output.txt` — фактический вывод демонстрации.
- `verification.txt` — результат проверок.
- `lab3_explanation.md` — подробное описание работы и подготовка к защите.

## Управление

При создании героя: 1 — воин, 2 — следопыт, 3 — маг; затем введите имя длиной до 20 символов.

В лагере: 1 — экспедиция, 2 — снаряжение, 3 — торговец, 0 — выход. В экспедиции выбирается лес, склеп или логово дракона. В снаряжении выбирается предмет из инвентаря. У торговца: 1 — покупка, 2 — продажа, 0 — назад.

Для первого знакомства выберите воина и лес. Перед экспедицией здоровье восстанавливается автоматически. При поражении герой теряет половину золота с округлением вниз. Прогресс существует только в памяти и при выходе не сохраняется, как и в исходном примере.
